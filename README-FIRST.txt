SOLEA BAY RESORT & SPA - STEP 1 (design system + Home page)
Fictional demo website by PrimeLaunchDigital

WHAT IS IN THIS ZIP
  soleabay-site/   <- the website. Upload everything INSIDE this folder.
  README-FIRST.txt <- this file (do not upload it)

------------------------------------------------------------
1) UNZIP ON ANDROID
------------------------------------------------------------
Open the "Files by Google" app > Downloads > tap soleabay-step1.zip > Extract.
You now have a folder called soleabay-site with 7 files:
index.html, 404.html, styles.css, main.js, favicon.svg, robots.txt, netlify.toml

------------------------------------------------------------
2) PUT IT ON GITHUB (new repository)
------------------------------------------------------------
1. In Chrome open github.com and sign in.
2. Tap the + (top right) > New repository.
3. Repository name: solea-bay-resort   (any name is fine). Choose Public. Tap Create repository.
4. On the empty repository page tap "uploading an existing file".
5. Tap "choose your files", open the soleabay-site folder, select ALL 7 files
   (long-press one file, then tick the others) and tap Open.
6. Wait until all 7 files are listed, then tap Commit changes.

------------------------------------------------------------
3) PUBLISH WITH NETLIFY (free)
------------------------------------------------------------
1. Open app.netlify.com and log in (choose "Log in with GitHub").
2. Tap Add new project > Import an existing project > GitHub.
   Allow access to your new repository if asked, then pick solea-bay-resort.
3. Leave "Build command" EMPTY. Publish directory is already set to "." by netlify.toml.
4. Tap Deploy. After about a minute your site is live at a *.netlify.app address.
5. Optional: Site configuration > Change site name, for a cleaner address.

------------------------------------------------------------
4) WHAT TO CHECK ON YOUR PHONE
------------------------------------------------------------
- The hero photo, villa photos and gallery strip load (they come from Pexels).
- The menu button opens a full-screen menu and closes again.
- The header turns dark as you scroll.
- The WhatsApp button is bottom-right (placeholder number for now).
- Rooms, Dining, Experiences, Gallery, About, Contact and Booking Inquiry show
  the "still being built" page until Step 2 - that is expected.

Photos: free-to-use images from Pexels, loaded straight from their servers for
this preview. In Step 2 we can switch to photos stored inside the project.
